## 🐾 Featured Project

### [Mioo — Pet Adoption Platform](https://miooapp.com)

A free platform for responsible dog and cat adoption in Bolivia that connects adopters, private owners and shelters. It includes pet profiles, lost and found reports on a map, and adoption coordination.

* **Mobile:** React Native + Expo
* **Backend:** Go + PostgreSQL
* **Landing:** Next.js
* **Availability:** [App Store](https://apps.apple.com/app/id6782881097) · [Google Play](https://play.google.com/store/apps/details?id=com.mioo.app)

### More projects

* **[The Wild Oasis (client)](https://the-wild-oasis-website-dussan-freire.vercel.app/)** — Cabin booking site with Next.js, Tailwind CSS, Supabase and Google auth.
* **[iPhone 15 Clone](https://dussanfreireapple.vercel.app/)** — Apple landing page replica with Next.js, GSAP and Three.js.
* **[Your Recipes](https://your-recipes-ftuz.vercel.app/)** — Recipes CRUD app with Next.js, TypeScript and Supabase.
